# Intro

Iceburg is a sealed-bid primary-issuance protocol for tokenized securities. It runs the first sale of a tokenized equity, fund share, or bond as a published rule instead of a private decision: the issuer fixes the sale's terms before any bid is seen, bidders submit sealed bids against those terms, and the clearing price and every bidder's allocation are computed from the revealed bids, rather than decided by the issuer or by Iceburg.
